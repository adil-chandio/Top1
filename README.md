# Top1 — MONARCH 3-Channel Production Studio

Clean, bloat-free home for the MONARCH 3-channel studio (`Monarch Cam`, `Extinct Life`, `MONARCHs Edit`), shared 3D/writing production engine, and ecosystem ops.

## Layout

- `studio/` — 3-channel production coordinator, quality/release gates, private Google Drive delivery verification, test suite, and `CUSTOMIZABLE_STUDIO_SYSTEM_PROMPT_ROMAN_URDU.md`.
- `channels/monarch_cam/` — Active Channel #1 verified market intelligence, competitor cohorts, reference craft forensics, and archived English script/caption alignment.
- `engine/panama_plus_3d_kit/` — Proven Three.js WebGL + `.glb` + Playwright multi-worker cinema engine and 7 episode recipes (`ep_ancient_bear`, Orca, B2B, Night Shift, EP5, Mafia Temple).
- `engine/workflow_templates/` — Reusable 6-chunk cloud render workflow templates (inert until enabled).
- `engine/cinema_v4/` — Automated script quality/anti-slop/story gates (`tools/`), MIT dramaturgy & hook references (`refs/`), and hybrid 3D depth-reprojection engine (`prime/`).
- `ops/` — `monarch_ctl.py` multi-repo control CLI, `b2b_revenue_kit/`, and studio strategy/architecture docs.

## Storage Hygiene

Rendered videos, audio stems, frame sequences, and `.glb`/`.blend` binaries are git-ignored and never committed to Git. Final review deliverables are uploaded privately to Google Drive with verified checksums.
