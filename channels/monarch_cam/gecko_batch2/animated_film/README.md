# Animated gecko concept

Original procedural Three.js geometry, skin texture, articulated legs and gait cycle, with animated illustrative microstructure. Rendered using headless Chromium and FFmpeg; no generated images are used. Render with `npm ci`, Chromium and FFmpeg installed, then `CHROMIUM=/path/to/chromium FFMPEG=/path/to/ffmpeg npm run render`. Set `GECKO_STILLS=1` for review stills.

QC: 12 seconds, 540x960, 24 fps, H.264/AAC; all 288 frames and audio stream decoded. Stills at 2, 6 and 8 seconds visually checked. Movement and anatomy are approximations, the microstructure is schematic, and this is not at the Dailymotion reference's quality. Sound is synthesized; it was decoded but not listened to. No narration. Not a final or a Batch 2 pass.
