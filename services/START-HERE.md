# START HERE

Bhai, ye folder tumhara business ka ghar hai. Product code (`src/`, `tools/`) ko chhua nahi — sab kuch yahan hai.

## Sabse pehle ye 3 file padho (10 minute)

1. **`PLAN.md`** — poora plan: abhi kya, kab, kitne paise mein.
2. **`MISTAKES.md`** — wo 10 ghaltiyan jo sab karte hain. Ye skip mat karo.
3. **`offers/`** — teen offers ki asli copy, price, aur scope.

## Aaj kya karna hai

`PLAN.md` ke aakhir mein "Aaj ke 3 kaam" hai. Bas wo teen.

## Repo mein kya hai (2 minute)

```sh
node services/tools/inventory.mjs     # dekh lo kya maujood hai, kya nahi
node services/tools/render-budget.mjs # aap kab tak kitne video bana sakte ho
```

## Har folder kya hai

| Folder | Kaam | Kab chahiye |
| --- | --- | --- |
| `offers/` | 3 offers ki copy + pricing | Abhi — pehla client lene se pehle |
| `design/` | Posts, taglines, outreach DM | Hafta 1 |
| `ops/` | Contract, pricing calculator, client process | Pehla paid client se pehle |
| `drive/` | Drive setup + folder structure | Jab pehla delivery karo |
| `automation/` | Agentic system ka blueprint | Mahina 2 |
| `website/` | Site par kya add karna hai | Hafta 1 |
| `tools/` | Standalone scripts | Jab zaroorat ho |

## Sabse zaroori baat

Tumhara engine **generator nahi, renderer** hai. `scenes.js` mein har film haath se likhi hai. Agentic system banane ke liye **parametric moves library** banana padega — poora detail `automation/ARCHITECTURE.md` mein hai. Ye 3–4 mahine ka kaam hai, 6 hafte ka nahi.

Aur Offer C ke bina bhi tum **abhi** paise kama sakte ho — Offer A ready hai, proof maujood hai. Sirf order lene ka raasta chahiye (email + form). Wo `website/HOMEPAGE-SECTIONS.md` mein hai.
