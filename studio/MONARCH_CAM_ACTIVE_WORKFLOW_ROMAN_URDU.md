## Har batch ke andar structure
1. Input/evidence inspect karo; text-only discovery ko watched/heard evidence na banao.
2. Actual work execute karo; artifact aur findings preserve karo.
3. Gate check: pass / fail / unresolved, specific reasons ke saath. Report likhna akela pass nahin.
4. Failure par bounded R&D: actual issue → suitable existing solution/docs/maintained repo/licensed asset → small actual trial → inspected comparison → accept ya reject. README/source search/install ko successful execution nahin ginna.
5. Substantial whole-batch result deliver karo; repeated tiny process updates nahin. Diagnostic upload explicitly diagnostic, final delivery nahin.

## Department zimmedariyan
- Creative direction: composition, materials/colour, visual hierarchy aur story promise.

- Story/script: causal explanation, purposeful beats, opening ka earned payoff.
