## Operating agreement

Ek waqt mein Monarch Cam. Doosre channel par tabhi jana jab user delivered video dekh kar explicitly bole. Intermediate research, design, debugging aur revision approvals delegated. Current scope 20-second humpback/orca integrated proof hai, full film/publishing nahi. Diagnostic final nahi. No purchases without authorization.

Goal: original art-directed storytelling, meaningful motion design, typography where useful, integrated 3D/compositing, precise sound and music. $1000/min reference craftsmanship ambition hai, spending approval ya guaranteed quality score nahi. Best/viral/superior claims unmeasured nahi karne.

## End-to-end sequence, stage names stable for persistent queue

| Stage | Internal work | Mandatory exit evidence |
|---|---|---|
| intelligence | current relevant channel/market plus specialist studio references; sources actually inspect | findings, uncertainty, dated research and opportunity decision |
| idea | demand + originality + production feasibility comparison | selected angle, alternatives and reasons |
| story | question, mechanism, stakes, payoff | beat map, source-backed narrative |
| script | source ledger, original narration, visual story, sound architecture | story_design and edit_sound_blueprint evidence |
| feasibility | designed representative frames, hardest integrated sequence, licensing | art_direction, asset_provenance, integrated_motion_test; combined actual motion/audio MP4 |
| production | animation, custom graphics, typography, compositing, scoring, sound, mix, cleanup | each craft department's actual artifacts and specific findings; final MP4 + attribution |
| qc | picture-only, audio-only, combined, reference comparison, technical checks | exact reviewed MP4 hash, defect-free specialist attestations, independent artifact reviewer |
| packaging | current title/thumbnail references and original execution | promise-content match, actual artifacts and review |
| delivery | full decode, post-QC integrity, private channel-folder upload | Drive receipt/link with size/checksum |

Fresh research at EVERY stage. Recency of check is not source publication date. Narrative evidence can be old authoritative paper; trend/tech compatibility checks need appropriate freshness. Current 72h check limit is a configurable engineering threshold, not universal evidence expiry law.

## Specialist roles (implementation versus availability)

Coordinator executes trusted CLI workers, captures history/retries, checks evidence contracts. Creative director establishes design system. Research worker collects relevant fresh evidence. Story worker structures explanation. Animation/motion/compositing/audio specialists produce actual craft artifacts. Reviewer sees/hears actual media independently. R&D worker supplies tested alternatives on retry.

Roles are work contracts, not proof separate agents exist. Existing runtime integration gap remains; workers/reviewer/R&D require configured actual equipped runtimes. No screenshot/transcript-only sound review. No claims of independent review based only on different executable names.

## Art direction standard

Design reference research must inspect accessible actual work: motion studios, premium explainers, title sequences, broadcast/commercial storytelling, and relevant social examples. Track URLs, observed timings where actually reviewed, elements to learn and elements inappropriate to our story. No unlicensed music/SFX extraction or copying signature sequences.

Design boards must establish composition, visual hierarchy, colour/material system, typography behaviour, information design and physical/graphic integration. No obligatory effect count. Restrained scientifically legible sequence can be better than overloaded graphics.

## Integrated proof, before full effort

Test representative difficult sequence with animal motion + scene + graphic explanation + deliberate typography choice + compositing + sound/music together. Fixed-camera diagnostic alone insufficient. Selected AI concept alone insufficient. Compare same representative content against reference criteria; document differences instead of declaring victory.

## Sound is authored, not wallpaper

Plan environment, perspective, focal details, designed emphasis, musical structure, narration space and deliberate silence. Licensed production music/recordings considered alongside generated options; AI output not default premium assumption. Asset rights and attribution per file. No measured call/sonar implication from invented wildlife sound. Use dynamic contrast; no whoosh on every move. Mix intelligibility, clipping/harshness, mono translation, peaks/loudness and sync checks; metrics not a substitute for listening. Packed texture/material formats likewise require correct decoding, not just loading a file.

## R&D recovery loop

1. Classify actual issue and measurable/observable acceptance criteria.
2. Existing tested solution → official docs → maintained repo/licensed asset → adaptation → custom, in that order when suitable.
3. Limit shortlist to 1–3 relevant candidates; inspect provenance/licence/security/version/compatibility.
4. Small meaningful actual trial. Record baseline versus candidate quality AND total setup/render/rework cost. Faster but worse is not accepted improvement.
5. Independent production/reviewer validation; guidance itself does not advance a stage.
6. Pin accepted implementation, preserve baseline and rollback.

`STUDIO_RD_COMMAND` hook is implemented on stage retry. R&D report fields validated; candidate claims/test_evidence are attestations, not externally verified by coordinator. Downloading/running repos is NOT automatic in coordinator. Trusted workers must inspect before execution. Three-attempt budget includes R&D; no endless search or retry loops. Failed candidate does not become tested library knowledge.

## Tested-solutions record format

Store accepted solutions with source URL/version, licence notice, problem, tested environment, actual input/output hashes, comparison, timing, limitations, reviewer findings and rollback. Recheck compatibility before reuse. No record may claim success based solely on README. Library curation by equipped worker remains required; report validator alone is not an automatic discovery agent.

## Internal quality, no user micromanagement

Departments cannot self-certify with adjective `premium`. Specific observations, reasons and verified artifact links required. Typographic effects can be deliberately not applicable; sound/compositing/finishing cannot silently disappear. Full video exact hash reviewed; modified final requires re-review. Delivery is not user acceptance and never unlocks next channel automatically.
