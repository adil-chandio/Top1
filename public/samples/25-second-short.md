# The 25-Second Script

A free prompt and example from Top1 Kits. This file gives you a writing and editing plan, not a rendered video.

## How to use it

1. Copy the prompt below into your AI chat. Replace the topic with your own idea and set the language to Roman Urdu or English.
2. Review the narration aloud; shorten it if it doesn’t fit 25 seconds. Verify each factual claim, and use your own footage or assets you have permission to publish.
3. Build the shots in your video editor or visual tool. Leave room for captions and keep stock UI or mockups generic unless a real interface is necessary.

## Copy-ready prompt

```text
Plan a 25-second faceless 9:16 explainer for Shorts or Reels.

Topic: Phone ki storage full kyun ho jaati hai?
Audience: everyday Android users. Show one useful action: check which files take up space before deleting anything.
Language: conversational Roman Urdu in Latin letters. Keep common phone UI labels in English. Use roughly 45–55 spoken words total.

Deliver three beats: 0–4 seconds (visual hook), 4–18 seconds (explain with a visible example), 18–25 seconds (payoff and one practical next step).
For each beat, give one timestamp, exact voiceover, one short on-screen caption, and one visual direction with framing and motion. Keep visuals practical to create without filming a face.

Use one main color and clear visual contrast. Don’t invent device menus, statistics, or guarantees. Where menus differ, describe the action rather than a specific button. Add a one-line check of any claims or assets that need verifying before publishing.
```

## Hand-written example plan

| Time | Voiceover (Roman Urdu) | Caption | Shot direction |
| --- | --- | --- | --- |
| 0–4s | “Phone full? Pehle dekho space ja kahan rahi hai.” | **Phone full?** | Close-up on a generic storage bar. It slides into the red as the question appears. |
| 4–18s | “Videos aur downloads waqt ke saath jama ho sakte hain. Phone ki Settings mein Storage kholo aur dekho kaunsi category sab se zyada jagah le rahi hai.” | **Storage check karo** | Photo, video, and download tiles enter one by one. Cut to a generic Storage chart with categories, no brand-specific menus. |
| 18–25s | “Bari files pehle review karo. Zaroori cheez ka backup rakho; jo nahi chahiye, sirf woh hatao.” | **Pehle review, phir delete** | Zoom into a short list of file cards. Mark one KEEP, one REVIEW. Leave room for the caption. |

**Edit check:** Read the script on a timer, and verify the Storage screen on the device used in the reel. Menu names vary. Don’t show personal files or promise a fixed amount of recovered space.
