# Fresh YouTube market pass — first Extinct long

This gate comes before any topic recommendation. It is the correction to the
retracted GitHub-first pass.

## Cohort design

- [ ] Define the channel promise in one sentence without selecting a topic.
- [ ] Identify at least three direct long-form channels with a comparable promise.
- [ ] Keep the same format: narrated evidence-led extinct-life/palaeontology,
      not Shorts, TV clips, news-only items, livestreams, or unrelated animation.
- [ ] Record a retrieval date in UTC.
- [ ] Sample at least five usable videos per direct channel where the platform
      surface allows it.
- [ ] Add context-only channels separately; never mix them into direct cohorts.
- [ ] Record exclusions and why they were excluded.

## Per-video receipt

For every included video:

- [ ] exact YouTube video ID and watch URL;
- [ ] title as displayed;
- [ ] listed upload date;
- [ ] runtime;
- [ ] displayed views and stated age window;
- [ ] channel and cohort;
- [ ] thumbnail URL/receipt and actual visual inspection status;
- [ ] opening hook and when the premise becomes clear;
- [ ] chapter/beat progression or transcript observation;
- [ ] format notes and any confound;
- [ ] no claim that views prove the topic caused performance.

## Pattern extraction

- [ ] title promise categories;
- [ ] thumbnail focal subject, text count, contrast, and promise match;
- [ ] opening visual grammar;
- [ ] evidence arrival time;
- [ ] mechanism/setting/payoff structure;
- [ ] uncertainty and limitation handling;
- [ ] recurring format opportunities;
- [ ] overused or saturated treatments;
- [ ] open gaps that can be supported by primary evidence.

## Topic gate

Only after the cohort report exists:

- [ ] create 3–5 new candidate topics from a documented market gap;
- [ ] run the idea scorecard;
- [ ] locate primary evidence for each candidate;
- [ ] build claim/rights/visual-proof notes;
- [ ] stop if the candidate is only a GitHub dataset or a competitor title;
- [ ] get owner selection before script or render.

## Privacy and rights

- [ ] keep private Drive links and raw reference media out of repo manifests;
- [ ] use reference videos for market observation, not production footage;
- [ ] do not copy thumbnails, music, voice, or clips into the film;
- [ ] preserve source URLs/IDs and retrieval notes only;
- [ ] no upload, schedule, sharing change, or publication in this pass.
